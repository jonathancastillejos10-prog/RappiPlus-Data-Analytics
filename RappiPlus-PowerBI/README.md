# RappiPlus — Data Analytics & Power BI Dashboard

## 📊 Descripción del proyecto

Proyecto de análisis de datos desarrollado a partir de información de ventas, productos y marketing de **RappiPlus**.

El objetivo fue transformar datos transaccionales en información útil para analizar el desempeño comercial, la rentabilidad, el comportamiento de los clientes y el rendimiento de las inversiones de marketing.

El proyecto combina **Python para el análisis y preparación de datos** con **Power BI para la construcción de un dashboard interactivo** orientado a la toma de decisiones.

---

## 🎯 Objetivos

* Analizar el desempeño de las ventas.
* Identificar los productos y categorías con mayor participación.
* Evaluar ingresos, costos y rentabilidad.
* Analizar el gasto en marketing.
* Analizar el comportamiento de los usuarios dentro del funnel de compra.
* Evaluar resultados de un experimento A/B.
* Construir un dashboard ejecutivo en Power BI.

## 🔎 Principales análisis

### Ventas y productos

Se analizaron los ingresos y unidades vendidas por producto y categoría para identificar los principales generadores de ventas.

El producto con mayor volumen de unidades vendidas fue:

**Laptop-Gaming-16GB — 144,198 unidades**

### Marketing

Se analizó la distribución de la inversión entre diferentes canales:

* Organic: $913,533.01
* Paid Search: $863,088.21
* Social: $918,043.21

### Funnel de conversión

Se analizaron las principales etapas del recorrido del usuario:

| Etapa            | Usuarios |
| ---------------- | -------: |
| First Visit      |    7,796 |
| Select Item      |    7,582 |
| Begin Checkout   |    7,208 |
| Add to Cart      |    7,634 |
| Add Payment Info |    6,250 |
| Purchase         |    6,240 |

### Análisis A/B

Se compararon dos grupos para evaluar el impacto de una variante experimental:

| Grupo     | Usuarios | Compras | Conversión |
| --------- | -------: | ------: | ---------: |
| Control   |    4,965 |     779 |     15.69% |
| Treatment |    5,035 |     820 |     16.29% |

El análisis estadístico obtuvo un **p-value de 0.416**, por lo que no se encontró evidencia estadísticamente significativa de una diferencia entre ambos grupos con un nivel de significancia de 5%.

## 💡 Insights principales

* Las ventas están fuertemente concentradas en la categoría de **Electrónica**.
* Laptop-Gaming-16GB destaca como el producto con mayor volumen de unidades vendidas.
* La inversión de marketing está distribuida de manera relativamente equilibrada entre los tres canales analizados.
* El funnel muestra una caída importante antes de la etapa de pago.
* El experimento A/B presentó una conversión ligeramente superior en el grupo Treatment, pero la diferencia no fue estadísticamente significativa.
