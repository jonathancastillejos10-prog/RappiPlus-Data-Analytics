# RappiPlus — Data Analytics

Proyecto de **Data Analytics y Business Intelligence** enfocado en el análisis de ventas, rentabilidad, comportamiento de usuarios, marketing y experimentación.

## 📊 Proyecto

El análisis utiliza **Python** para la exploración y preparación de datos, y **Power BI** para la construcción de un dashboard interactivo orientado a la toma de decisiones.

### 🔎 Áreas analizadas

* Ventas e ingresos
* Costos y rentabilidad
* Productos y categorías
* Inversión en marketing
* Funnel de conversión
* Análisis de cohortes
* A/B Testing
